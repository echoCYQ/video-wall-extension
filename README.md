# 视频分屏墙 Video Wall

## 这是什么

一个 Chrome 浏览器扩展，让你在**一个浏览器窗口的一个标签页内**同时显示多个网页。不用开好几个窗口来回切换，所有页面并排放在眼前。

你可以选择左右两栏、上下两栏、或者四宫格的排列方式。每个分屏都是一个完整的网页，能正常浏览、点击、播放视频。如果某个分屏里有视频在播放，还可以一键把视频铺满整个分屏区域，进度条、音量、快进全都能用。

适合的场景：同时盯好几个直播页面、多路监控画面同屏对比、一边看课程一边查资料、多个社交媒体同时刷。

## 怎么安装

1. 打开 Chrome 浏览器，在地址栏输入 `chrome://extensions` 按回车
2. 打开页面右上角的**开发者模式**开关
3. 点左上角的**加载已解压的扩展程序**按钮
4. 在弹出的对话框里选择 `video-wall-extension` 文件夹
5. 浏览器工具栏上会出现一个四色宫格图标，安装完成

建议点工具栏的拼图图标，把这个扩展**固定到工具栏**，方便随时使用。

## 怎么用

### 打开分屏

三种方式任选：

- **点工具栏图标**，弹出小窗口，选择左右双屏、上下双屏或四宫格
- **快捷键**：Ctrl+Shift+1 左右双屏，Ctrl+Shift+2 上下双屏，Ctrl+Shift+3 四宫格
- 打开后会在当前标签页旁边新建一个标签页，这个标签页里就是分屏界面

默认情况下，所有分屏会加载你当前正在看的那个网页。你也可以给每个分屏单独换网址。

### 每个分屏能做什么

分屏打开后，每个面板顶部有一排工具栏，从左到右依次是：

**编号** — 显示这是第几个面板

**地址栏** — 输入网址按回车，或者点"打开"按钮，这个面板就跳转到新网址

**标签** — 点击后弹出一个下拉列表，列出你当前浏览器里所有打开的标签页，选一个就直接加载到这个面板里。不用复制粘贴网址，直接从已打开的页面中选

**打开** — 加载地址栏里输入的网址

**刷新** — 刷新这个面板当前正在显示的页面

**铺满** — 如果面板里的网页有视频正在播放，点这个按钮会把视频铺满整个面板区域。铺满后视频保留原生控制条，进度条拖拽、音量调节、快进快退都能用

**还原** — 把铺满的视频恢复到原来页面中的位置和大小

**自动** — 开关按钮。开启后，面板检测到有视频在播放就自动铺满。默认是关闭的，需要你手动点一下才会开启。关掉就不自动铺满

**折叠** — 点一下把整个工具栏收起来，面板左上角只留一个半透明的小圆球（上面有面板编号）。再点圆球就展开恢复工具栏。折叠后视频画面不被遮挡，看视频更干净

**×** — 关闭这个面板。关闭后其余面板自动重新编号。只剩最后一个面板时不允许关闭

### 顶部工具栏

分屏页面最上方有一排全局工具栏：

- **左右双屏 / 上下双屏 / 四宫格** — 随时切换布局，切换时面板数量会自动调整（四宫格有 4 个面板，双屏有 2 个）。多出来的面板会被关闭，少出来的会新建
- **关闭** — 关掉整个分屏标签页

### 切换布局会怎样

从四宫格切到左右双屏：保留前两个面板，关闭后两个。

从左右双屏切到四宫格：新建两个面板，默认加载第一个面板的网址。

切换后面板会重新排列编号。

## 关于视频铺满

这个功能是专门为看视频设计的。当你在某个分屏里打开了一个有视频的页面（比如 B 站、YouTube、直播平台），点视频的播放按钮开始播放后：

- 点面板上的**铺满**按钮，视频会铺满整个面板区域，黑底等比缩放，不会有白边
- 铺满后浏览器原生的进度条、音量、全屏按钮都在底部，可以正常拖拽和点击
- 网站自己的播放器控制条会被自动隐藏，避免和原生控件重叠遮挡
- 点**还原**按钮恢复原状
- 如果你想让某个面板每次有视频播放就自动铺满，点**自动**按钮开启（默认关闭）

不开启"自动"的情况下，铺满完全由你手动控制，不会被反复打扰。

## 常见问题

**点开分屏后页面是空白的？**
有些网站（比如 Google 首页）设置了禁止被嵌入 iframe 的安全头。这个扩展已经通过 declarativeNetRequest 自动去除了大部分限制，但极少数网站用 JavaScript 主动跳出框架（frame-busting），这种属于浏览器安全机制，无法绕过。换个网站试试。

**视频没有自动播放？**
Chrome 的自动播放策略要求有声音的视频必须用户先和页面交互才能播放。在分屏里点一下视频画面或者播放按钮就行了。

**铺满后看不到进度条？**
确保你用的是最新版。当前版本铺满时会强制开启原生控制条，并隐藏网站自定义播放器控件，进度条一定可见可操作。如果还是看不到，可能是某些网站的 CSS 优先级极高，试试点"还原"再"铺满"。

**快捷键没反应？**
可能是和其他扩展或浏览器快捷键冲突。到 `chrome://extensions/shortcuts` 里检查和重新设置。

**能不能同时看四个不同的视频？**
可以。给四个面板分别输入不同的视频网址，各自播放各自铺满，互不干扰。

## 目录结构

```
video-wall-extension/
├── manifest.json       扩展清单，声明权限、快捷键、网络规则
├── rules.json          网络规则，去除 iframe 的 X-Frame-Options/CSP 限制
├── background.js       后台脚本，处理快捷键和打开分屏页面
├── content.js          内容脚本，注入每个 iframe 内，负责视频识别和铺满
├── wall.html           分屏网格页面，单标签页内的 iframe 容器
├── wall.js             分屏页面逻辑，面板管理、布局切换、标签页选择
├── popup.html          工具栏弹窗界面
├── popup.js            弹窗逻辑
├── icons/              扩展图标
└── test/               测试页面
```

## 技术实现

扩展使用 Manifest V3 标准。核心原理是在一个 Chrome 扩展页面（wall.html）内用 CSS Grid 布局排列多个 iframe，每个 iframe 加载一个独立的网页。通过 declarativeNetRequest 的静态规则在网络层去除目标网站响应头中的 X-Frame-Options 和 Content-Security-Policy 字段，使绝大多数网站都能被嵌入 iframe。

视频铺满功能通过 content_scripts（all_frames: true）向每个 iframe 注入 content.js。content.js 默认不激活，只有收到来自 wall 页面通过 postMessage 发送的激活指令后才开始工作。它定时扫描页面中的 video 元素，找到正在播放且面积最大的视频后，用注入的 CSS 把视频固定铺满整个 iframe 视口，同时强制开启原生媒体控件、隐藏网站自定义控制层。wall 页面与 iframe 之间通过 postMessage 双向通信，消息来源通过校验 origin 为 chrome-extension://{extensionId} 确保安全。

面板工具栏支持折叠为透明圆球，通过 CSS display 切换实现。每个面板可独立关闭，关闭后自动重新编号并调整布局。标签页选择功能通过 chrome.tabs.query API 获取所有打开的标签页列表，过滤掉浏览器内置页面和分屏墙自身后供用户选择。
